Tower Defense - Primera Versión (Java)
Descripción
Este proyecto es una primera versión de un juego tipo Tower Defense desarrollado en Java con Swing.
Incluye torres defensivas, enemigos en movimiento y un sistema básico de combate automático con representación visual del ataque.

Clases incluidas:

Enemy → enemigos del juego
Tower → torres defensivas
GamePanel → lógica del juego y renderizado
Main → punto de entrada
🚀 Compilación y ejecución
1. Abrir terminal en la carpeta del proyecto
Ubícate en el directorio donde se encuentra Main.java.

2. Compilar
javac Main.java
